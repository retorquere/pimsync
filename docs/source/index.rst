**pimsync** is a command line tool to synchronise calendars and contacts
between different storages, including CalDAV and CardDAV. Pimsync is a
successor and reimplementation of vdirsyncer, and is free and open source
software.

Installation
------------

The `project README`_ contains documentation on compiling and installing from
source.

.. _project README: https://git.sr.ht/~whynothugo/pimsync#pimsync

Distributions packages are available on:

- Alpine Linux Edge, in the testing repositories.
- ArchLinux, via the Arch User Repositories.
- Nix, via nixpkgs unstable.
