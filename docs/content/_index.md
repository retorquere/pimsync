# Introduction

This is the documentation for vdirsyncer 2.x. The project and documentation are
still in progress and experimental. Only use this if you want to help find
issues. Be sure to keep frequent backups.

The configuration file has some changes with respect to version 0.x. See the
[migration guide](/docs/migration-guide/) for details on how to adapt an
existing configuration file.
