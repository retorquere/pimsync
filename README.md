This is the repository for `pimsync`, the rewrite and successor of `vdirsyncer`.

For the original Python implementation see: <https://github.com/pimutils/vdirsyncer>

# User documentation

User documentation is provided as man pages. They can be built with `make man`.
The same man pages can be rendered as HTML pages. These can be generated with
`make html`.

# Developer documentation

Documentation for libraries can be built with `cargo doc`.

The documentation for the latest commits are published at:

- https://mirror.whynothugo.nl/vdirsyncer/main/vstorage/
